# باغ حفظ

برنامهٔ وب (PWA) فارسی برای تشویق کودکان ۷ تا ۱۲ سال به حفظ قرآن. فعلاً جزء ۳۰ (سورهٔ نبأ تا ناس). بدون اینترنت و بدون سرور کار می‌کند و پیشرفت هر کودک فقط روی همان دستگاه ذخیره می‌شود.

هر آیه‌ای که کودک حفظ می‌کند، یک گیاه در باغش می‌شود. گیاه‌ها با مرور فاصله‌دار (لایتنر: ۱، ۲، ۴، ۸، ۱۶ روز و بعد ۳۰ روز) رشد می‌کنند و به گل می‌رسند. غیبت یک روزه رشتهٔ روزها را نمی‌شکند.

## فایل‌ها
| فایل | کار |
|---|---|
| `index.html` | کل برنامه (صفحه، استایل، منطق، متن آیات و معنی) |
| `sw.js` | سرویس‌ورکر برای کار آفلاین |
| `manifest.json`، `icon-*.png` | نصب روی گوشی و تبلت |
| `fonts/` | فونت شهرزاد نو (SIL OFL) |
| `audio/` | صدای قاری (خودتان اضافه می‌کنید) |
| `tools/make-audio.py` | ساخت فایل صوتی هر سوره از فایل‌های آیه‌به‌آیه |

## اجرا
روی GitHub Pages یا هر میزبان ایستا بگذارید (نصب و آفلاین‌شدن به `https` نیاز دارد). برای آزمایش محلی:
`python3 -m http.server` و بازکردن `http://localhost:8000`.

## افزودن صدا (استاد پرهیزگار)
۱. فایل‌های آیه‌به‌آیهٔ سوره‌های ۷۸ تا ۱۱۴ را با نام `114001.mp3` (سه رقم سوره + سه رقم آیه) در یک پوشه بگذارید.
۲. اجرا (نیاز به ffmpeg):
   `python3 tools/make-audio.py پوشهٔ_آیه‌ها`
   خروجی: `audio/078.mp3` تا `audio/114.mp3` و `audio/timings.json`، یعنی ۳۸ فایل به‌جای ۵۶۴ فایل. هر آیه فقط یک بار دوباره فشرده می‌شود و زمان شروع هر آیه دقیق است.
۳. در برنامه: والدین ← «بررسی فایل‌های صوتی» ← «ذخیرهٔ صدا برای کار بدون اینترنت».

برنامه فایل‌های آیه‌به‌آیه (`audio/078001.mp3`) را هم مستقیم می‌خواند، اگر ترجیح می‌دهید. بدون صدا هم کامل کار می‌کند و کودک آیه را بلند می‌خواند.
پیش از انتشار عمومی، مجوز بازنشر صدا را از منبع آن بررسی کنید.
